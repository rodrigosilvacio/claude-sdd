Tutorial de BMAD Method

Aviso: este tutorial usa o Projeto_Exemplo “Lista de Tarefas”, o mesmo dos outros módulos. Os comandos abaixo foram copiados da fonte oficial.

Fonte oficial e versão

  • Fonte oficial: repositório do BMAD Method.
  • Data_Consulta: 14/11/2026.
  • Versão: v6.12 (estável); v7 em preview alpha.
  • Licença: MIT.
  • Agentes de IA: a fonte consultada fala apenas em “ferramenta de IA” e não traz uma lista de agentes suportados (lista não informada na fonte).

Este tutorial usa a versão estável v6.12. A linha v7 está em preview alpha e não é usada aqui.

O fluxo em três etapas

Com o BMAD Method você instala o método, pede ajuda com bmad-help e constrói com bmad-build, sempre dentro da sua ferramenta de IA.

  1. Instalar Instala a versão estável v6.12.
  2. Pedir ajuda Invoca bmad-help na ferramenta de IA.
  3. Construir Invoca bmad-build na ferramenta de IA.

Pré-requisitos

A fonte oficial pede Node.js 20.12 ou superior e Python 3.10 ou superior. O uv também é necessário. Tenha ainda uma ferramenta de IA, na qual você invoca os comandos do BMAD Method.

Instalação

Na pasta do Projeto_Exemplo, execute o comando abaixo para instalar a versão estável v6.12.

npx bmad-method install

Passo a passo

Siga os quatro passos na ordem. Use Anterior e Próximo para navegar.

  1. Conferir os pré-requisitos

    Node.js 20.12+ e Python 3.10+; o uv é necessário.

  2. Instalar a versão estável v6.12 
    npx bmad-method install
  3. Invocar bmad-help na ferramenta de IA 
    bmad-help
  4. Invocar bmad-build na ferramenta de IA 
    bmad-build

Estrutura de arquivos

A fonte consultada não descreve a estrutura de pastas e arquivos criada pelo BMAD Method. Por isso este tutorial não mostra um mockup dessa estrutura.

Resultado esperado

Ao final, o BMAD Method v6.12 está instalado e você invocou bmad-help e bmad-build na sua ferramenta de IA, usando o Projeto_Exemplo “Lista de Tarefas”.

Solução de problemas comuns

A fonte consultada não traz uma seção de solução de problemas. Se a instalação falhar, confira primeiro os pré-requisitos: Node.js 20.12+, Python 3.10+ e uv. Depois consulte o repositório oficial.
