Tutorial de OpenSpec

O OpenSpec propõe, aplica e arquiva mudanças com requisitos em Markdown, orientadas por comandos no agente de IA. A licença informada na fonte é MIT.

Projeto_Exemplo: este tutorial usa o projeto “Lista de Tarefas”, o mesmo dos tutoriais das outras ferramentas, para que você possa comparar os fluxos.

Fonte oficial e versão

  • Fonte oficial: https://github.com/Fission-AI/OpenSpec.
  • Documentação citada no README: https://openspec.dev/docs (não foi acessada na consulta).
  • Data de consulta: 14/11/2026.
  • Versão: versão não informada na fonte.

Pré-requisitos

É preciso ter Node.js 22.12.0 ou superior e um agente de IA compatível. A fonte informa suporte a mais de 30 assistentes de IA, sem listar todos.

O ciclo do OpenSpec

O ciclo tem quatro etapas: explorar, propor, aplicar e arquivar. Cada uma é acionada por um comando no agente de IA.

  1. Explorar Investigar a ideia com o agente, antes de propor.
  2. Propor Gerar a pasta da mudança com proposta, especificações, design e tarefas.
  3. Aplicar Implementar as tarefas de tasks.md.
  4. Arquivar Mover a mudança concluída para archive/.

Instalação e passo a passo

Siga os seis passos, na ordem, usando o botão Próximo. Cada comando tem um botão para copiar.

  1. Instalar o OpenSpec

    Exige Node.js 22.12.0 ou superior. Alternativas: brew install openspec ou script curl/PowerShell.

    npm install -g @fission-ai/openspec@latest

  2. Inicializar o projeto

    openspec init

  3. Explorar a ideia

    /openspec-explore

  4. Propor a mudança

    Gera openspec/changes/<nome>/ com proposal.md, specs/, design.md e tasks.md. No Codex, use $openspec-propose.

    /openspec-propose <descrição>

  5. Aplicar a mudança

    /openspec-apply-change

  6. Arquivar a mudança

    Move a mudança para openspec/changes/archive/.

    /openspec-archive-change

Resultado esperado

Depois de propor uma mudança, a pasta openspec/ do projeto fica com esta estrutura. Ao arquivar, a mudança vai para archive/.

Solução de problemas comuns

  • A instalação falha: confira se o Node.js é 22.12.0 ou superior.
  • O npm não é uma opção: a fonte também cita brew install openspec e scripts curl/PowerShell.
  • O comando /openspec-propose não é reconhecido no Codex: use $openspec-propose.
  • Outros erros: consulte a fonte oficial, que não lista outros problemas conhecidos.
