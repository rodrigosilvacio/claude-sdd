Tutorial de GSD

O GSD é um sistema de meta-prompting, engenharia de contexto e SDD. Cada fase do projeto percorre um laço de cinco etapas: Discuss, Plan, Execute, Verify e Ship. Os artefatos citados na fonte oficial são STATE.md e CONTEXT.md.

Projeto_Exemplo: este tutorial usa o projeto “Lista de Tarefas” como exemplo.

O laço do GSD

O laço tem cinco etapas, repetidas a cada fase do projeto.

Linha do tempo de uma fase

Uma fase percorre as cinco etapas na ordem abaixo.

  1. Discuss Primeira etapa da fase.
  2. Plan Segunda etapa da fase.
  3. Execute Terceira etapa da fase.
  4. Verify Quarta etapa da fase.
  5. Ship Quinta e última etapa da fase.

Como começar

Em um projeto novo, use /gsd-new-project. Em um código que já existe, use /gsd-onboard. O instalador pergunta qual runtime você usa e se a instalação é global ou local. Entre os agentes citados na fonte estão Claude Code, OpenCode, Antigravity CLI, Kimi CLI, Kilo, Codex, Copilot, Cursor e Windsurf, entre outros.

Passo a passo

Use os botões Anterior e Próximo para percorrer os sete passos.

  1. Instalar o GSD Core O instalador pergunta o runtime e se a instalação é global ou local. Comando: 
    npx @opengsd/gsd-core@latest
  2. Iniciar um projeto novo Para código existente, use /gsd-onboard. Comando: 
    /gsd-new-project
  3. Discuss Primeira etapa do laço da fase.
  4. Plan Segunda etapa do laço da fase.
  5. Execute Terceira etapa do laço da fase.
  6. Verify Quarta etapa do laço da fase.
  7. Ship Quinta etapa do laço da fase.
