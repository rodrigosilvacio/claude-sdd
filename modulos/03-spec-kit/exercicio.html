Exercício de GitHub Spec Kit

Pratique o fluxo do GitHub Spec Kit sobre o Projeto_Exemplo, a Lista de Tarefas. Primeiro ordene as etapas do fluxo; depois siga o checklist no seu computador. O exercício conta como concluído quando todos os itens estiverem marcados.

Ordene as etapas do fluxo

Use os botões Subir e Descer para colocar as etapas na ordem em que os comandos são executados no chat do agente, e depois use Verificar ordem.

  1. /speckit-plan
  2. /speckit-converge
  3. /speckit-constitution
  4. /speckit-tasks
  5. /speckit-specify
  6. /speckit-implement

Checklist

Marque cada item depois de executá-lo. Sua marcação fica salva neste navegador.
