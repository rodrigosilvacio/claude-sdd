Tutorial de GitHub Spec Kit

O GitHub Spec Kit conduz o SDD no chat do agente, com comandos para constituição, especificação, plano, tarefas, implementação e convergência. Os artefatos do projeto ficam na pasta .specify/.

Projeto_Exemplo: neste tutorial você aplica o fluxo à Lista de Tarefas, o projeto descrito em Projeto de exemplo.

O fluxo em seis etapas

No chat do agente, o fluxo segue seis comandos, na ordem do diagrama. Repita /speckit-implement e /speckit-converge até a convergência.

  1. Constituição Primeira etapa do fluxo, com /speckit-constitution.
  2. Especificar Segunda etapa, com /speckit-specify.
  3. Planejar Terceira etapa, com /speckit-plan.
  4. Tarefas Quarta etapa, com /speckit-tasks.
  5. Implementar Quinta etapa, com /speckit-implement.
  6. Convergir Última etapa, com /speckit-converge; repita com implementar até a convergência.

Passo a passo

Use os botões Anterior e Próximo para percorrer os oito passos. Cada comando tem um botão para copiar.

  1. Instalar o Specify CLI

    Exige Python 3.11+ e uv.

    uv tool install specify-cli
  2. Criar o projeto 
    specify init my-project --integration copilot
  3. Definir a constituição 
    /speckit-constitution
  4. Especificar 
    /speckit-specify
  5. Planejar 
    /speckit-plan
  6. Gerar as tarefas 
    /speckit-tasks
  7. Implementar 
    /speckit-implement
  8. Convergir

    Repita implement e converge até a convergência.

    /speckit-converge

O que o projeto contém

O projeto criado pelo specify init guarda os artefatos na pasta .specify/.

Extensões opcionais

A fonte oficial lista duas extensões opcionais, adicionadas com os comandos abaixo.

specify extension add bug
specify extension add assess
