GitHub Spec Kit

Este módulo mostra como conduzir o SDD com o GitHub Spec Kit, no chat do agente, com os comandos de constituição, especificação, plano, tarefas, implementação e convergência. Você faz o tutorial, pratica com um exercício e responde a um quiz de 5 questões; a aprovação exige 70% de acertos.

Trilha do módulo

Siga os itens na ordem. A lição mostra o selo “concluída” depois que você a marca.
