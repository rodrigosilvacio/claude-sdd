Spec Kitty

Este módulo apresenta o Spec Kitty, um fluxo SDD em que cada work package roda em seu próprio git worktree e um revisor diferente do autor confere o trabalho. Ele tem um tutorial, um exercício com checklist e um quiz de 5 questões; a aprovação exige 70% de acertos.

Trilha do módulo

Siga os itens na ordem. O tutorial mostra o selo “concluída” depois que você o marca.

  1. Tutorial de Spec Kitty Lição de 80 minutos.
  2. Exercício de Spec Kitty Exercício de 90 minutos.
  3. Quiz de Spec Kitty Quiz de 15 minutos.
