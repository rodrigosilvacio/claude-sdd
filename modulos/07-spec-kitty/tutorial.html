Tutorial de Spec Kitty

O Spec Kitty é um fluxo SDD em que cada work package roda em seu próprio git worktree e um revisor diferente do autor confere o trabalho. O CLI é gratuito e funciona com mais de 20 agentes.

Projeto_Exemplo: este tutorial usa o projeto “Lista de Tarefas” como exemplo.

Fonte oficial e dados consultados

  • Fonte oficial: spec-kitty.ai e guia de primeiros passos.
  • Data da consulta: 14/11/2026.
  • Versão: spec-kitty-cli 3.2.7.
  • Licença: MIT.
  • Custo: CLI gratuito.

O ciclo do Spec Kitty

O ciclo tem sete etapas: especificar, planejar, tarefas, implementar, revisar, aceitar e mesclar. Cada etapa tem um comando /spec-kitty.* no chat do agente.

Linha do tempo de um work package

Cada etapa tem um comando próprio. Na implementação, o work package roda em seu próprio git worktree.

  1. Especificar Comando /spec-kitty.specify.
  2. Planejar Comando /spec-kitty.plan.
  3. Tarefas Comando /spec-kitty.tasks.
  4. Implementar Comando /spec-kitty.implement.
  5. Revisar Comando /spec-kitty.review.
  6. Aceitar Comando /spec-kitty.accept.
  7. Mesclar Comando /spec-kitty.merge.

Passo a passo

Use os botões Anterior e Próximo para percorrer os dez passos.

  1. Instalar o CLI Exige Python 3.11+, pipx e git. Comando de instalação: 
    pipx install spec-kitty-cli
  2. Inicializar o projeto Crie o projeto com uma chave --ai. Em repositório existente, use spec-kitty init --ai claude; para vários agentes, --ai claude,codex. 
    spec-kitty init my-project --ai claude
  3. Conferir .kittify/ e os arquivos de comandos do agente O init cria .kittify/ e arquivos de comandos do agente (por exemplo .claude/). Para adicionar outro agente depois, use spec-kitty agent config add <chave>.
  4. Especificar Descreva o Projeto_Exemplo “Lista de Tarefas”. 
    /spec-kitty.specify
  5. Planejar Gere o plano a partir da especificação. 
    /spec-kitty.plan
  6. Gerar as tarefas Gere as tarefas do plano. 
    /spec-kitty.tasks
  7. Implementar Cada work package roda em seu próprio git worktree. 
    /spec-kitty.implement
  8. Revisar Um revisor diferente do autor confere o trabalho. 
    /spec-kitty.review
  9. Aceitar Aceite o trabalho revisado. 
    /spec-kitty.accept
  10. Mesclar Mescle o resultado aceito. 
    /spec-kitty.merge

Estrutura criada pelo init

O comando spec-kitty init my-project --ai claude cria estas pastas no projeto.
